# Exercícios de Python

Este repositório reúne uma coleção de exercícios de programação em Python, com foco em lógica de programação e manipulação de strings. A ideia é praticar conceitos fundamentais da linguagem, como entrada e saída de dados, estruturas condicionais, laços de repetição e operações com texto.

## Objetivo

- Desenvolver habilidades de lógica e resolução de problemas.
- Praticar fundamentos da linguagem Python.
- Explorar operações com strings e algoritmos simples.
- Aumentar a familiaridade com exercícios de programação do cotidiano.

## Estrutura do repositório

```text
Exercicios/
├── Strings/
│   ├── ContagemDeCaractes.py
│   ├── ContagemDePalavras.py
│   ├── InverterFrase.py
│   └── palindromo.py
└── README.md
```

## Exercícios incluídos

- Contagem de caracteres
- Contagem de palavras
- Inversão de frase
- Verificação de palíndromo

## Como executar

Cada script pode ser executado diretamente com Python. Exemplo:

```bash
python "Strings/ContagemDeCaractes.py"
```

Ou para qualquer outro arquivo:

```bash
python "Strings/InverterFrase.py"
```
